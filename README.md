# حسابات برج مكة — نسخة آمنة

هذه الحزمة لا تحتوي على بيانات السكان داخل ملفات الموقع، حفاظًا على الخصوصية.

## استعادة النسخة الاحتياطية
1. ارفع `index.html` و`sw.js` إلى مستودع GitHub، واترك `manifest.json` و`icon.svg` الموجودين.
2. افتح التطبيق من GitHub Pages.
3. ادخل إلى **الإعدادات والبيانات**.
4. اختر **استيراد نسخة احتياطية**.
5. اختر ملف JSON الذي حفظته من التطبيق القديم.
6. ستظهر رسالة بعد الاستيراد بعدد السكان والعمليات.
7. لا تستخدم **مسح كل البيانات**.

مفتاح التخزين المحلي ثابت: `hasabat_borg_makka_v1`.
النسخة الاحتياطية الأصلية يجب ألا تُرفع إلى GitHub العام لأنها تحتوي على بيانات محاسبية وأسماء.
