# حسابات برج مكة
تطبيق PWA عربي لإدارة حسابات اتحاد الشاغلين.
- تخزين محلي على الجهاز عبر localStorage.
- يعمل كواجهة مستقلة عند إضافته للشاشة الرئيسية.
- اشتراكات السكان والإيرادات والمصروفات.
- ترحيل الرصيد الشهري.
- حساب مرتب وسلف البواب.
- إضافة مسميات الإيرادات والمصروفات من داخل شاشة العملية.
- تقرير شهري وطباعة/حفظ PDF.
- تصدير نسخة احتياطية JSON.
